# 📋 Study02 ToDoList

매일 10~20개의 할 일을 관리하는 **개인용 할 일 관리 웹 앱** 프로젝트입니다.
설치나 로그인 없이 브라우저에서 바로 실행되고, 새로고침해도 데이터가 유지되는 것을 목표로 합니다.

| 버전 | 주소 | 화면 구성 |
|---|---|---|
| 🖥️ **웹 버전** | https://rlayejinn-ui.github.io/Study02_ToDoList/ | 데스크톱 2단 레이아웃 (좁은 화면에서는 1단) |
| 📱 **모바일 버전** | https://rlayejinn-ui.github.io/Study02_ToDoList/mobile_version/ | 600px 단일 컬럼 (초기 버전) |

두 버전은 같은 `localStorage` 데이터를 공유하므로, 같은 브라우저에서는 어느 쪽으로 열어도 같은 할 일 목록이 보입니다.

> 요구사항 전체는 [PRD.md](PRD.md)를 참고하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| ✏️ 할 일 관리 | 추가 · 수정(인라인 편집) · 삭제, 완료 항목 일괄 삭제 |
| ✅ 완료 체크 | 체크 시 취소선 표시, 미완료 항목이 위로 정렬 |
| 🗂️ 카테고리 | 업무 / 개인 / 공부 분류와 필터 메뉴 (카테고리별 개수 표시) |
| 📊 진행률 | 전체 진행률 바 + 카테고리별 완료 현황 (웹 버전은 카테고리별 미니 바) |
| 💾 데이터 유지 | `localStorage`에 자동 저장 → 새로고침·재시작 후에도 유지 |

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (ES6+)
- 외부 라이브러리 · 프레임워크 · 빌드 도구 · 서버 없음
- 저장소: 브라우저 `localStorage`

## 파일 구조

```
Study02_ToDoList/
├── index.html          # 웹 버전 화면 구조 (데스크톱 2단)
├── style.css           # 웹 버전 스타일
├── app.js              # 웹 버전 동작 로직
├── mobile_version/     # 모바일 버전 (초기 단일 컬럼 디자인)
│   ├── index.html
│   ├── style.css
│   └── app.js
├── PRD.md              # 제품 요구사항 문서
└── README.md
```

## 실행 방법

- **온라인**: 위 표의 주소로 접속 (GitHub Pages)
- **로컬**: 저장소를 내려받아 `index.html`(웹 버전) 또는 `mobile_version/index.html`(모바일 버전)을 브라우저에서 열기 (별도 설치 불필요)

> 할 일 데이터는 각 브라우저의 `localStorage`에 저장되므로, 기기·브라우저마다 목록이 따로 관리됩니다.
